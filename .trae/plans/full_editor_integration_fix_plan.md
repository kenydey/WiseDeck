# 完整编辑器集成问题修复计划

## 问题分析

根据用户反馈，完整编辑器页面存在以下问题：

1. **缺少项目ID** - 页面显示"缺少项目ID"错误
2. **空白画布** - 没有正确显示正在预览的PPT内容
3. **缩略图不显示** - 底部幻灯片缩略图区域为空
4. **保存不同步** - 完整编辑器修改后无法同步回PPT编辑器

## 根本原因

1. **项目数据传递问题**：full_editor.html 没有正确接收和传递项目数据
2. **幻灯片数据加载问题**：main.js 无法正确解析项目数据
3. **缩略图渲染问题**：CanvasManager 没有正确渲染幻灯片缩略图
4. **跨窗口通信问题**：缺少保存后同步到父页面的机制

## 修复方案

### 1. 修复项目数据传递
- 修改 HTML 模板，添加项目数据脚本标签
- 确保项目ID和幻灯片数据正确传递到前端

### 2. 修复数据加载
- 修改 main.js，正确解析项目数据
- 添加数据加载失败的错误处理

### 3. 修复缩略图渲染
- 完善 CanvasManager 的缩略图渲染逻辑
- 确保支持 iframe 内容渲染

### 4. 实现跨窗口通信
- 添加 window.postMessage 通信机制
- 实现保存后自动刷新父页面

1. 点击"完整编辑"按钮，新窗口正确显示PPT内容
2. 底部缩略图区域显示所有幻灯片预览
3. 在完整编辑器中修改并保存后，PPT编辑器页面自动刷新显示更新内容
