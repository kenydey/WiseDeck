# 完整编辑器元素选择功能修复计划

## 问题分析

### 问题1：左侧缩略图无预览
当前状态：左侧缩略图只显示数字占位符（1, 2, 3...），没有实际幻灯片内容预览
原因：当前 `renderThumbnails()` 使用简单的文字占位符，没有使用 iframe 显示实际内容

### 问题2：中间预览区域无法选择元素
当前状态：点击预览区域中的元素没有任何反应，无法选中和修改元素
原因：iframe 内部的元素没有绑定点击事件，需要注入编辑器脚本实现元素选择

## 修复方案

### 任务1：修复缩略图预览
- 修改 `SlideManager.renderThumbnails()` 方法
- 使用 iframe 显示实际的幻灯片 HTML 内容
- 添加样式确保缩略图正确显示

### 任务2：实现元素选择功能
- 创建编辑器脚本注入逻辑
- 在 iframe 加载完成后注入点击事件绑定
- 实现选中框显示（8个调整手柄）
- 实现元素拖拽移动

### 任务3：实现属性面板联动
- 选中元素后更新右侧属性面板
- 实现属性修改同步到元素

## 文件修改

### 1. `main.js`
- 修改 `renderThumbnails()` 方法，添加 iframe 预览
- 添加 `setupIframeCommunication()` 方法
- 添加元素选择和拖拽逻辑

### 2. `full_editor.css`
- 添加缩略图 iframe 样式
- 添加选中框和调整手柄样式

4. 测试验证

## 技术要点

- 使用 iframe 的 srcdoc 属性显示幻灯片内容
- 在 iframe 的 window.load 事件后注入脚本
- 使用 postMessage 进行跨域通信
- 实现选中框的动态创建和定位
